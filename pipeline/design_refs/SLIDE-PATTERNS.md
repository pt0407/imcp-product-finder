# Slide Patterns — Per-Type Specifications

## Cover Slide

| Element | Spec |
|---------|------|
| Title | 40-52pt, 700 weight, centered or left-aligned |
| Subtitle | 20-24pt, 400 weight, 30% lighter than title |
| Author / date | 14-16pt, bottom-left or bottom-center |
| Visual | Full-bleed background image with 60% overlay, or solid color |
| Logo | Top-right or bottom-right, 48px max height |
| Word count | 10-20 words total |

## Section Divider

| Element | Spec |
|---------|------|
| Section number | 96pt, 700 weight, accent color or 10% opacity |
| Section title | 36-44pt, 700 weight |
| Subtitle (optional) | 18-20pt, 400 weight, muted |
| Background | Contrasting color (dark if content slides are light) |
| Word count | 5-10 words |

## Content Slide (Text)

| Element | Spec |
|---------|------|
| Assertion headline | 28-36pt, 700 weight, full sentence |
| Body | 18-22pt, 400 weight, 3-5 bullets max |
| Bullet spacing | 8-12px between bullets |
| Bullet indent | 24px from left margin |
| Supporting visual | Right column (40% width) — icon, image, or chart |
| Word count | 30-50 words (live) / 60-100 words (async) |

## Data Slide

| Element | Spec |
|---------|------|
| Assertion headline | 28-36pt, states the data insight |
| Chart | 60-70% of content area |
| Annotation callout | 14-16pt, points to key finding |
| Source line | 10-12pt, bottom of chart area |
| Supporting text | 0-2 bullets max, next to or below chart |
| Word count | 15-25 words (excluding chart labels) |

## Big Number / Stat Callout

| Element | Spec |
|---------|------|
| Number | 72-120pt, 700 weight, accent color |
| Unit / label | 20-24pt, 400 weight, directly below number |
| Context line | 16-18pt, muted, "up from X" or "compared to Y" |
| Layout | Centered, vertically centered in content zone |
| Word count | 5-15 words |

## Comparison Slide

| Element | Spec |
|---------|------|
| Headline | "X outperforms Y on Z metric" (assertion) |
| Layout | Two columns, equal width, with divider line |
| Column headers | 22-24pt, 700 weight |
| Column content | 16-18pt, 3-5 bullets per column |
| Highlight | Green check / red X for quick scanning |
| Word count | 40-60 words |

## Quote Slide

| Element | Spec |
|---------|------|
| Quote text | 28-36pt, italic or regular, centered |
| Attribution | 16-18pt, 500 weight, below quote |
| Background | Contrasting — dark or accent color |
| No quotation marks | Use visual weight and positioning instead |
| Word count | 15-30 words |

## Timeline / Roadmap Slide

| Element | Spec |
|---------|------|
| Headline | Assertion about the timeline |
| Timeline | Horizontal, 3-5 milestones max |
| Milestone label | 14-16pt, 500 weight |
| Date | 12-14pt, 400 weight |
| Current marker | Accent color, larger dot |
| Word count | 25-40 words |

## Thank You / CTA Slide

| Element | Spec |
|---------|------|
| Headline | "Next step" or specific ask — NOT "Thank You" |
| CTA | 24-28pt, 700 weight, one specific action |
| Contact info | 16pt, email/website |
| Background | Match cover slide treatment |
| Word count | 10-20 words |

The "Thank You" slide is the most wasted slide in every deck. Replace it
with a specific call to action or next step.
